# FinMind — персональний облік фінансів із ШІ-асистентом

WPF (.NET 8, C# 12) · MVVM (CommunityToolkit.Mvvm) · SQLite + EF Core · LiveCharts2 · Google Gemini REST API

## Запуск
1. Потрібні **Windows 10/11**, **.NET 8 SDK** і Visual Studio 2022 (робоче навантаження «.NET desktop development»).
2. Відкрийте папку з `FinMind.csproj` у Visual Studio → **Restore NuGet** → `F5`.
   Або в терміналі: `dotnet run -c Release`.
3. Розділ **Налаштування** → вставте Gemini API ключ ([Google AI Studio](https://aistudio.google.com/apikey)) →
   «Перевірити з'єднання» → «Зберегти».
   (Також можна задати змінну середовища `GEMINI_API_KEY`.)

Дані зберігаються в `%LocalAppData%\FinMind\` (`finmind.db`, `settings.json`).

## Примітки
- Назва моделі Gemini змінюється в налаштуваннях (за замовчуванням `gemini-2.5-flash`). Модель 1.5 Flash з ТЗ у Google вже знята з підтримки.
- Валюта в налаштуваннях задає лише символ відображення (UAH ₴ / USD $ / EUR €), без перерахунку курсів.
- Модель `BudgetLimit` присутня в БД, але інтерфейсу для лімітів поки немає.
- API ключ зберігається у `settings.json` відкритим текстом — не діліться цим файлом.
